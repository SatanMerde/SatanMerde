### 💡 About Me

Hi! I'm an independent software creator based in France 🇫🇷, dedicated to designing fast, elegant, and uncompromising open-source software. 

My work centers on **desktop and mobile multiplatform development**, **audiophile sound pipelines**, and **modern product design**. I combine rapid AI-assisted development workflows with rigorous architecture, deep UI/UX refinement, and extensive testing to ship robust consumer-ready applications.

- 🎵 **Audio Engineering & Multiplatform**: Architecting cross-platform apps on Android, Windows, Linux, macOS, TV, and WearOS.
- 🎨 **Obsession with UI/UX**: Delivering fluid animations, frosted glassmorphism, dynamic palette theming, and syllable-accurate lyrics.
- ⚡ **Pragmatic Engineering**: Using modern LLMs and agentic pair-programming to accelerate software iteration while maintaining high code quality and test coverage.
